# ASSIGNMENT 6

This folder contains responsive Flexbox and Grid layouts for Assignment 6.

## Files

- `index.html` – main page with links to all tasks
- `q1.html` and `q1.css` – portfolio layout using Flexbox
- `q2.html` and `q2.css` – 4-column product gallery using Grid
- `q3.html` and `q3.css` – 3-section homepage using Flexbox
- `q4.html` and `q4.css` – dashboard layout using Grid
- `q5.html` and `q5.css` – pricing section using Flexbox
- `q6.html` and `q6.css` – responsive blog layout using Grid areas
- `q7.html` and `q7.css` – CSS loading animation
- `q8.html` and `q8.css` – photo gallery with Grid hover transforms

Open `index.html` to view all questions.
